# Report template

Header: fixture, date, source of footage (e.g. "public stream"), model and settings used, and the badge rule below.

Badge rule: sections from the model's actual output are marked REAL; anything written for illustration is marked ILLUSTRATIVE; model guesses stay tagged [inferred]. If the footage is not your own team, say so in the header.

Sections:
1. Match summary (3-5 sentences).
2. Event timeline (merged from all segments).
3. Shot/chance log.
4. Defensive notes.
5. Rotation and pace.
6. Clip index: category, minute, do/don't, coaching point per clip.
7. Where we can attack / where we must defend well.
8. Limits: what the camera angle, lighting or model could not see.
